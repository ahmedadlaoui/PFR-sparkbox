# SparkBox

**SparkBox** is a platform that connects entrepreneurs and investors.  
Entrepreneurs can register their startups and showcase them to potential investors.  
Investors can browse available startups, make investment offers, and start private conversations with startup owners.

## How it works

- **Entrepreneurs** create and manage a profile for their startup, including key information about their project.
- **Investors** can view listed startups, send investment offers, and negotiate directly through private messages.
- **AI Insights** are provided to investors, analyzing startup financial numbers and estimating the potential of each project to help investors make smarter decisions.

## Technologies Used

- **PHP** (Laravel Framework)
- **MySQL** (Database)
- **Blade** (Laravel's Templating Engine)
- **Tailwind CSS** (Frontend Styling)
- **JavaScript** (For dynamic interactions)
- **AI Algorithms** (For financial analysis and startup potential evaluation)
